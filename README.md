# Basic Go Server with HTML & CSS
This is a simple Go web server that serves static HTML and CSS files and handles a basic form submission. It's a beginner-friendly project to understand how Go interacts with the web using the `net/http` package.

## 🌐 Features
- Serves static files like HTML and CSS from the `static/` directory
- Handles GET and POST requests
- Displays a welcome page at `/`
- Processes a contact form at `/form`
- Responds with a simple message at `/hello`

## 🚀 Running the Server
1. Make sure you have Go installed: [https://golang.org/dl](https://golang.org/dl)
2. Clone this repo and navigate to the folder:
   ```bash
   git clone https://github.com/ranit1803/Basic-Go-Server
   cd Basic-Go-Server
3. To run the server : go run main.go
